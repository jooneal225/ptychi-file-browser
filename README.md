Useful for nagivating the file structure generated by pear. Works with both ptychi-pear and my data saver for RPI.

Requires standard python packages, scipy, h5py, pandas, tifffile, pyqt5, and pyqtgraph.

## pg_image_tools/

The interactive plotting (click-to-measure, cursor readout, lineout + 25%-75%
resolution metric, display filters, right-click menu) lives in the
`pg_image_tools/` package. It is self-contained -- it imports nothing from this
project, only numpy, scipy, PyQt5 and pyqtgraph -- so it can be dropped into
other GUIs, and may eventually be split into its own repository.

See the docstring at the top of `pg_image_tools/__init__.py` for usage, and run
`python -m pg_image_tools` for a standalone demo.
